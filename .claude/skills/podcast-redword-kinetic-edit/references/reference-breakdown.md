## Rhythm
- Key-word rule: one red word per **clause**; it holds for the whole clause (≈1.2–1.5 s), then hard-cuts to the next red word on the
  next clause. No transitions between red words.
- Side words change on every stressed syllable (≈0.4–0.6 s each).
- Overlay density never drops: every frame from 0.27 s to 12.67 s carries at least one text element + HUD + handle.
- Graphics only cut on speech, never on a picture cut, except the final guest cut, which also switches caption style (side → centre).
